[x] Live platform ratings for the 5 review badges + Review Badge Widget — Testimonials > Review Sources

[x] Google Places Reviews import (1.0.5 — includes/review-import.php, max 5 per listing)
    Reads either endpoint: legacy maps.googleapis.com Place Details or Places API (New).
    Mode is auto | legacy | new, set on the import screen or via the
    bpbtb_google_reviews_endpoint filter. Auto tries legacy first and falls back only on
    an access refusal (REQUEST_DENIED etc.), never on NOT_FOUND or an empty listing —
    those would cost a second billable call to be told the same thing.
    Dedupe keys are content-derived so the two endpoints agree and switching re-imports nothing.
    The legacy endpoint cannot be enabled on a Cloud project created after 1 March 2025.

[x] Surface a failing review platform (1.0.5 — includes/admin-source-health.php)
    Admin notice + Site Health test. Reads BPBTB_Review_Sources::CACHE only, never fetches:

    an HTTP request to Google and Facebook on every wp-admin page load.
    Only reports platforms that are connected AND live-source — "not connected" is a choice,
    and a typed figure has no credential to expire.
    Classifies the fallback as stale | typed | local and words itself accordingly; only
    "local" is misleading under a platform logo.
    Dismissal is keyed on an md5 of platform+message, so a new failure re-notifies.

[x] Facebook one-click OAuth (1.0.5 — includes/admin-facebook-connect.php)
    Popup to api.bplugins.com/facebook-auth/, result collected server-side from
    /wp-json/facebook/v1/get-token. No app id or secret ships with the plugin.
    Two deliberate departures from the business-review implementation:
      - the state is minted server-side, kept in a transient bound to the user, single-use,

        straight to JS, putting the Page token through the DOM and the network panel.
    A failing connection offers Reconnect, not just Disconnect — an expired token still
    fills both fields, so the card used to read as "connected" and offer nothing useful.
    Hooks a new do_action( 'bpbtb_review_source_actions', $slug, $platform ) in
